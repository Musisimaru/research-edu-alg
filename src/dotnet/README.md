# Crawler

Трёхзвенный «червяк» на Aether.Physics2D: полигон для сравнения алгоритмов обучения
(random baseline, дальше — GA / NEAT / PPO). Цель эпизода — доползти до `x = 8 м`
за 1500 шагов (25 с при 60 Гц).

## Запуск

```bash
dotnet run --project src/Crawler.Cli -- <субкоманда> [параметры]
```

## Субкоманды

### `watch` (по умолчанию)

Окно Raylib, ручное управление червяком.

| Клавиша | Действие |
|---|---|
| `Q` / `A` | мотор первого сустава (вперёд / назад) |
| `W` / `S` | мотор второго сустава |
| `R` | сброс эпизода |
| `Esc` | выход |

По окончании эпизода червяк подсвечивается: **зелёный** — дошёл до цели, **красный** — вышло время.

### `watch-random`

То же окно, но действия выдаёт случайная политика (seed=1, hold=10).

### `random` — headless baseline с записью рана

```bash
dotnet run --project src/Crawler.Cli -- random [--budget N] [--batch N] [--hold N] [--top N] [--no-traj]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--budget N` | `2000000` | бюджет рана в шагах среды (env steps) |
| `--batch N` | `100` | эпизодов в одном батче (гоняются параллельно) |
| `--hold N` | `10` | сколько шагов удерживать одно случайное действие |
| `--top N` | `3` | скольким лучшим эпизодам батча записывать полную траекторию |
| `--no-traj` | — | не записывать траектории вообще (реплей будет ре-симулировать) |

Результат — каталог `runs/<algo>_<timestamp>/` в корне репозитория:

```
runs/random_20260919_232216/
  manifest.json        # алгоритм, git-коммит, конфиг среды, гиперпараметры
  metrics.csv          # кривая обучения: total_env_steps,best_reward,mean_reward (пишется живьём)
  episodes.jsonl       # строка на каждый эпизод: seed, reward, steps, reached, policy, traj
  trajectories/*.traj  # бинарные по-шаговые траектории (только топ-N за батч)
```

Эпизоды без `.traj` воспроизводятся детерминированной ре-симуляцией по seed —
результат совпадает с записанным бит-в-бит.

### `replay` — реплей одного эпизода

```bash
dotnet run --project src/Crawler.Cli -- replay <run> [episode-id]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `<run>` | — | ран: полный путь \| имя каталога под `runs/` \| `latest` |
| `[episode-id]` | лучший по reward | id эпизода из `episodes.jsonl` |

В HUD — бейдж `[recorded]` / `[re-simulated]` и накопленный reward.

### `ghosts` — несколько эпизодов «призраками» в одном мире

```bash
dotnet run --project src/Crawler.Cli -- ghosts <run> [--top N] [--episodes 1,2,3]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `<run>` | — | ран (путь \| имя \| `latest`) |
| `--top N` | `6` | взять N лучших эпизодов рана |
| `--episodes a,b,c` | — | явный список id (перебивает `--top`) |

Полупрозрачные червяки разных цветов, камера следит за лидером,
легенда с id и reward. Финишировавшие замирают и тонируются по исходу.

### `grid` — сетка реплеев

```bash
dotnet run --project src/Crawler.Cli -- grid <run> [--top N]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `<run>` | — | ран (путь \| имя \| `latest`) |
| `--top N` | `16` | N лучших эпизодов, раскладываются ~квадратной сеткой (16 → 4×4) |

У каждой ячейки своя камера; рамка ячейки по финишу — зелёная/красная.

### `report` — HTML-дашборд по всем ранам

```bash
dotnet run --project src/Crawler.Cli -- report [-o out.html]
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-o путь` | `runs/report.html` | куда писать отчёт |

Один самодостаточный HTML: наложенные кривые обучения всех ранов (best — сплошная,
mean — пунктир), распределение наград по батчам (медиана + полоса p25–p75 + min/max),
таблица ранов (эпизоды, best, % дошедших, git-коммит). Открывается просто в браузере;
для графиков используется Chart.js с CDN.

## Управление воспроизведением (replay / ghosts / grid)

| Клавиша | Действие |
|---|---|
| `Space` | пауза / продолжить |
| `←` / `→` | покадрово (в паузе) |
| `+` / `-` | скорость ×2 / ÷2 (до ×16) |
| `R` | рестарт |
| `Esc` | выход |

Во всех режимах: **зелёный** — дошёл до цели, **красный** — таймаут.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `CRAWLER_RUNS_DIR` | переопределяет корень `runs/` (по умолчанию ищется корень git-репозитория, затем каталог с `*.slnx`) |

## Структура

- `src/Crawler.Core` — среда (`CrawlerEnv`), политики (`IPolicy`, `RandomPolicy`),
  прогон эпизодов (`EpisodeRunner`) и инфраструктура записи/чтения ранов (`recording/`).
- `src/Crawler.Cli` — субкоманды, Raylib-вьюверы (`viewers/`), генератор отчёта (`report/`).
